# Cap Bon Explorer

Portail touristique interactif et responsive pour découvrir le Cap Bon.
Mini-projet Web, ISET Nabeul, 2026–2027.

## Fonctionnalités
- Recherche, filtre par catégorie et tri par prix des activités
- Agenda des événements
- Simulation de réservation avec calcul du prix et remise de 10 % dès 4 personnes
- FAQ et formulaire de contact

## Technologies
HTML5, CSS3, JavaScript, Bootstrap 5

## Lancer le projet
Ouvrir `index.html` dans un navigateur.
